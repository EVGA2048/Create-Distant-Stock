# 远仓港单包修订与远仓仪表

## 已实现

- `distantstock:gauge` 仍为远仓请求台，不修改旧方块身份。
- 新增创造栏物品与方块 `distantstock:remote_gauge`（远仓仪表），使用 Create 工厂仪表原模型、四分格结构及网络绑定交互。需先像原版一样绑定仓储网络后放置。
- 远仓港新建收发缓存各一个方向槽，但收、发、退回共用一个占用限制；不能同时各存一包。两个自动化槽只是收发方向视图。
- 有包裹时持续显示，发送上升、接收下降。接收动画期间不允许手取/自动化提取；包裹离开后允许下一次输入。
- 包裹使用自身烘焙模型和 UV；顶部裁切高度为模型中传送门的 13.35/16。包裹宽度适配开口，不缩成小球、不画出顶盖以上的部分。
- 旧 NBT 的缓存大小和内容不截断。额外旧包裹可逐个排空，全部排空前拒绝新输入。收到的旧包裹优先排空，再发送旧出站缓存。
- 原始物品退回仍允许一个物品堆；需要多个槽的整批退回保持等待，不允许部分接收后继续重试造成重复。

## 验证结果与未完成边界

构建、资源引用检查和动画几何检查通过。`verifyDockMotion` 检查 16 种长宽组合、每种 301 个动画位置的逆向一致性、底部边界及顶部裁切范围。

尚未执行真实客户端/双服务器验收，也未用旧存档实测缓存迁移。须检查空闲包裹显示、六面自动化抢占、模拟插入、断线发送失败、接收中重启与旧多包库存排空。

远仓仪表本次补齐的是独立物品、方块、原版外观和基础交互；跨服生产请求、远程网络授权与回执接入尚未接到此新仪表。不能把它列为跨服自动生产功能已完成。
