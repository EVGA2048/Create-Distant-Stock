# 远仓成就

远仓使用独立成就页。设备与材料按取得物品解锁，不代表完成安装或成功运行。互通塔三个组件可分别取得，无需同时持有；护甲成就要求实际同时穿戴四件护甲。

| 成就 | 条件 |
|---|---|
| 以太初现 | 获得以太石英 |
| 精密共鸣 | 获得以太构件 |
| 远仓基石 | 获得远仓机壳 |
| 互通之柱 | 集齐互通塔基座、耦合器与以太谐振器 |
| 以太供给 | 获得一桶或一瓶以太 |
| 谐振锻造 | 获得谐振坚固板 |
| 随行储备 | 获得任意便携流体罐 |
| 远仓门户 | 获得远仓港 |
| 整装待发 | 获得远仓打包机 |
| 远方来件 | 获得远仓包裹 |
| 远程调度 | 获得便携终端或远仓请求台 |
| 按需补给 | 获得远仓仪表 |
| 脉冲订货 | 获得远仓红石请求器 |
| 链路观察 | 获得远仓监视器 |
| 物流体检 | 获得诊断蛙港 |
| 缓冲余量 | 获得缓存蛙港 |
| 运行档案 | 获得远仓日志台 |
| 留据可查 | 获得一张事件小票 |
| 状态可见 | 获得工况灯或声光报警器 |
| 谐振同步 | 同时穿戴全套谐振石英护甲，无需充能 |

父节点用于组织显示，不额外限制子节点解锁。仅谐振同步使用聊天广播，其余节点保留弹窗提示。
