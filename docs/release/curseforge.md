# Create: Distant Stock

**Take your Create logistics to another server.**

Distant Stock is a Create addon for Minecraft 1.21.1 on NeoForge. Browse a distant warehouse, place an order, and receive the packed goods through a cross-server shipping line. Build a central warehouse that supplies multiple survival servers, or connect factories running on different servers.

## Features

- Portable terminals and fixed Request Desks for browsing member warehouses and ordering supplies.
- Distant Packagers and Docks that connect cross-server shipping to local Create parcel logistics.
- Distant Gauges for automatic resupply and redstone-triggered requests.
- Rotationally powered interconnection towers, device coverage and Ether-powered parcel shipping.
- Monitors, event loggers, printed receipts, signal panels and industrial status lights.
- Join codes, warehouse membership and receiving dock groups for shared networks.
- English and Chinese interfaces, with in-game Ponder scenes.

Every warehouse retains its own Create network. Orders are packed at the source and delivered as parcels for the receiving server's local logistics to handle.

## Requirements and setup

Install **Distant Stock, Create 6.0.x and Transerver 0.1.x on both clients and servers**, along with their required dependencies. Use Minecraft **1.21.1**, **NeoForge** and **Java 21**. The current development environment uses NeoForge 21.1.231 and Create 6.0.10.

Cross-server shipping requires an administrator to run a **Transerver Router** and configure the server nodes. Once connected, players use join codes and dock addresses in-game. Build and power interconnection towers to support the distant devices and supply Ether for shipping when the default shipping cost is enabled.

Curios, Create: Deployer, Extra Gauges and Create: FluidLogistics are optional integrations.
