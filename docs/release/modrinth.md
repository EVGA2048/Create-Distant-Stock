# Create: Distant Stock

**Cross-server warehouses, real Create parcels.**

Order supplies on one server and have a warehouse on another server pack and ship them. Distant Stock connects your Create logistics through Distant Docks, with portable terminals for players and automation for factories.

## Build your shipping network

- **Request stock:** browse member warehouses from a portable terminal or Request Desk.
- **Move parcels:** route packages between servers, then hand them back to local Create logistics.
- **Keep factories supplied:** request remote stock automatically with Distant Gauges or trigger orders using redstone.
- **Power the infrastructure:** build interconnection towers with rotational power, device capacity and Ether shipping costs.
- **Watch your factory:** use monitors, event loggers, receipts, signal panels and industrial lights.
- **Share access:** organize warehouse members through join codes and route shipments to receiving dock groups.

Includes English and Chinese interfaces and Ponder scenes.

## Install and connect

**Minecraft 1.21.1 · NeoForge · Java 21**

Required on **both clients and servers**:

- Create 6.0.x (development baseline: 6.0.10).
- Transerver 0.1.x.
- Distant Stock and all dependencies required by those mods.

The current build uses NeoForge 21.1.231. Curios, Create: Deployer, Extra Gauges and Create: FluidLogistics are optional integrations.

An administrator must configure a **Transerver Router** and the participating server nodes before cross-server play. Players then create or join a distant network, register their local warehouses and set receiving addresses. In-game interconnection towers must be powered, and the default shipping cost requires Ether at the sending tower.
