# 以太谐振器旋转叉草案

用户要求 Create 风格与以太结合、可旋转、科幻信号塔轮廓。以原生 Create 安山结构和黄铜块纹理构建 U 形旋转叉。中心4×4晶体固定；两臂、浅蓝绝缘座及黄铜调谐板绕(8,0,8)竖轴整体旋转。模型为整数体块，仅居中1×1亮芯使用半像素边界。

fixed_mesh 与 rotor_mesh 分离，动画为离线验证，不是已接入游戏的方块渲染。旋转叉尺寸从x=-4至20，扫掠半径最大约12.2模型像素，游戏需考虑顶部横向空位；不应沿用满格静态碰撞而忽视转臂空间。

底座核心底面保留Create gearbox孔及竖直轴，上方黄铜夹座是本轮初稿。全部正式程序保持不变。
