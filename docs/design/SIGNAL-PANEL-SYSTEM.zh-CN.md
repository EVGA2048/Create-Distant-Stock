# 信号灯面板系统

## 结论

安山信号灯与黄铜信号灯不再各自占据一个完整方块，而是采用机械动力工厂仪表的四分格结构。同一个方块表面最多容纳四盏灯，每盏灯占用一个 8×8 槽位；同一方块内允许混装不同颜色的安山信号灯和黄铜信号灯。

外观、槽位选择、连接线段、方向箭头和拆卸方式均沿用工厂仪表的视觉语言。首次向原版工厂仪表面板加入信号灯时，远仓会把该面板转换为兼容面板，复制已有四分格和连接数据；原有仪表仍然可以正常使用。

## 设备分工

### 安山信号灯

- 每个物品带有固定颜色。
- 放入面板槽位后接收 0–15 的信号值。
- 首版在有信号时点亮，颜色由物品种类固定。
- 适合简单、直观、可远距离辨认的状态显示。

### 黄铜信号灯

- 灯体本身没有固定颜色。
- 首版根据输入强度分段显示红、橙、绿、青；无信号时为白色暗灯。
- 适合在同一灯位表示多种互斥状态，例如绿色为正常、橙色为等待、红色为故障。
- 后续再通过机械动力式滚轮设置颜色、优先级和保持时间，不增设传统配置界面。

### 原生工厂仪表连线

首版直接复用机械动力的工厂仪表连线，不另设传统配置界面：

1. 对来源仪表的具体槽位右键，记录来源。
2. 对目标信号灯槽位右键，完成连接。
3. 可以从多个来源连接同一盏灯；任意成功输入都会点亮灯。
4. 潜行并用扳手选中连接，可单独拆除该连接；直接拆灯不会影响同方块的其他三个槽位。

用已命名的命名牌右键灯位，可以单独为该灯命名。工程师护目镜会显示每盏灯的名称、底座材质、颜色与当前 0–15 输入。

## 信号来源

### 工厂仪表

直接读取工厂仪表连接的成功状态。首版输出如下：

- 条件满足：15；
- 条件未满足：0。

后续可增加库存比例等模拟量输出，但不会改变首版连接格式。

### 远仓仪表

远仓仪表实现统一的信号来源接口，可用滚轮选择输出频道。首版预留：

- 远仓链路是否在线；
- 最近一次请求是否成功；
- 目标网络是否有库存；
- 缓存数据是否过期。

远仓仪表外观上使用工厂仪表同规格的小型输出端子，连接线仍使用机械动力原版模型和材质。

## 多连接规则

- 安山信号灯允许多个来源连接到同一槽位；任意连接成功即输出 15。
- 黄铜信号灯接受相同的工厂仪表二值输入，也可从相邻红石读取 0–15 模拟量并据此变色。
- 来源所在区块未加载或设备失效时，该连接视为无信号，不主动加载来源区块。
- 连接不会跨服务器传递红石时序。远仓仪表只把已经同步到本服的远仓状态转换成灯信号，避免把装饰系统变成新的跨服协议。

## 存档结构

每个信号灯面板方块实体保存四个槽位。灯种、固定颜色和自定义名称保存在对应槽位的物品标记中；连线沿用机械动力的面板连接数据。首版不建立第二套平行连接图。灯位使用只读行为：它读取来源仪表的满足状态，但不会把自己当成生产配方、不会向物流网请求信号灯物品。

客户端只接收渲染所需的灯色、亮度和路径；信号求值始终在服务端完成。

## 当前实现边界

远仓复用机械动力提供的工厂面板槽位、连接线模型和连接数据，并使用同尺度的安山／黄铜灯体模型。这样能让工厂仪表和信号灯真正混装，也无需玩家学习第二套连线工具。代价是机械动力升级时需要回归测试面板数据兼容性；转换前后的槽位、过滤器和连线数据必须列入存档迁移测试。
