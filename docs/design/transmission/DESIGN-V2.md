# Distant Stock 视觉与玩法设计 V2

这份文档冻结当前美术方向，供效果图评审和后续模组实现使用。V2 不改现有正式资源。

## 核心概念

远仓网络不是“隔空复制物品”，而是一套以互通塔为基础设施、以太凝液为消耗介质、包裹为传输单位的 Create 物流网络。

- Create 物流负责把物品打成包裹、把包裹送入远仓港。
- 互通塔负责建立本服网络、维持区块加载并激活覆盖范围内的远仓设备。
- 跨服每成功发送一个包裹，发送端互通塔消耗 `250 mB` 以太凝液。
- 远仓港只处理包裹，不承担动力或流体输入。

## 内容清单

### 远仓请求器

落地方块，功能接近 Create 仓储请求器。交互后打开物流仓储网络的库存、购物车和下单界面。

- 造型：安山岩底座、黄铜桌面、大尺寸深色库存屏幕、短键盘。
- 已调谐：屏幕列表和右上网络灯为霁青色。
- 未调谐：网络灯熄灭，屏幕内容变灰。
- 不显示 IP、端口或 token。

### 便携式远仓请求器

手持物品，打开与远仓请求器相同的下单界面。

- 保留当前受 Create: Mobile Packages 启发的轮廓。
- 正式贴图统一为黄铜边框、工业铁机身、纸质清单和少量霁青网络像素。
- 调谐状态可以用物品组件保存，不需要为状态改变模型轮廓。

### 远仓港

一格方块，中心为开放式包裹泊位。四个水平面均可连接蛙港、漏斗、溜槽或其他物品交互；顶部同样保持开放。

- 四角立柱保护包裹，四边中段不设高墙。
- 离线：泊位底部为深色，四边网络发射条熄灭。
- 在线：四边发射条和泊位底面出现低强度霁青光。
- 传输中：包裹外出现半透明霁青传输场。
- 不设计动力轴、流体法兰或固定“正面”，模型应具有四向对称性。

### 远仓监视器

贴墙薄面板，主体是屏幕，不是多灯仪表盘。

- 屏幕显示本端/对端 TPS、链路状态和简化历史曲线。
- 右上角只有一个 Create 工厂风格指示灯。
- 建议默认阈值：`TPS >= 18` 绿色，`15 <= TPS < 18` 橙色，`TPS < 15` 红色；阈值配置化。
- 网络离线应在屏幕中显示，不占用 TPS 灯的颜色语义。

## 互通塔

互通塔为 `1×1` 占地的纵向多方块结构，由三种组件组成。

### 互通塔底座

- 多方块控制器。
- 南侧接收旋转应力，东侧接收以太凝液；最终实现时接口可随方块朝向旋转。
- 正面紫色液位窗表示储液，霁青状态灯表示网络已建立。
- 负责持有流体槽、应力需求、多方块状态、覆盖范围和区块加载票据。

### 互通塔塔架

- 可重复堆叠的桁架段，让整体真正具有信号塔轮廓。
- 中央透明管内的紫色介质表示以太凝液上行。
- 中部霁青线圈表示网络场耦合。
- 第一版可以固定使用三段；如果以后让高度决定覆盖范围，可以直接复用该组件。

### 以太谐振器

- 塔顶组件，四向黄铜调谐臂围绕紫色核心。
- 在线时端部镜片和向上的信号束呈霁青色。
- 离线时信号束消失；故障时镜片变红，但紫色介质仍保持原色。
- 负责完成结构识别并建立远仓网络场。

## 以太凝液

工作名：**以太凝液**（Aetheric Condensate）。

- 颜色：偏蓝的紫色，与紫水晶来源一致，但不能与下界传送门紫完全相同。
- 配方方向：`1000 mB 水 + 紫水晶材料 + 少量导能材料`，在动力搅拌盆中加热得到 `1000 mB`。
- 紫水晶材料和导能材料的准确数量留到平衡阶段决定。
- 每成功发送一个包裹消耗 `250 mB`；接收端不重复扣除。
- 扣液、移除包裹和网络发送应作为一次事务处理，失败时不得吞包或吞液。

## 统一视觉语义

| 颜色 | 唯一含义 |
|---|---|
| 紫色 | 以太凝液、储量和塔内介质 |
| 霁青 | 网络调谐、覆盖和包裹传输场 |
| 绿色 | TPS 健康 |
| 橙色 | TPS 警告 |
| 红色 | TPS 严重或设备故障 |
| 灰色 | 离线、未调谐 |

结构材质只使用 Create 6 的安山岩机壳、工业铁、黄铜机壳和铜机壳。发光色不大面积铺在外壳上。

## 暂不实现

- 流体远仓港。
- 能量远仓港。
- 独立探测仪和额外控制台。
- 精确覆盖半径与高度分级。
- 最终配方材料数量。

这些内容不会进入第一轮模型与贴图，避免范围再次失控。
