# Remote Fluid Package compatibility

Optional compatibility for Create: FluidLogistics 1.0.1 by Yision (declared BSD-3-Clause in its mod metadata).
Distant Stock does not bundle FluidLogistics and registers this item only when FluidLogistics is installed.
The remote parcel directly subclasses FluidLogistics FluidPackageItem; fluid storage, unpacking and dynamic fluid rendering remain owned by FluidLogistics.
The shell keeps the original 12x10 package/window layout while remapping only cardboard pixels to Distant Stock pale blue. Transparent window pixels and cyan glass accents are preserved.
