# 远仓机壳护甲 V4 · 立体光学组件

在 V3 浅色钻石护甲轮廓上添加低矮的立体配件：阶梯薄肩壳、头盔侧置光学件和短眉檐、紧凑的背部校准模块、小型护踵。保留浅蓝灰机壳与温白高光，无黄铜大外骨骼、武器或背部喷口。

参考用户提到的 Create Stuff 'N Additions 的装备/器具方向，具体几何和贴图均为本稿原创。项目页：https://www.curseforge.com/minecraft/mc-mods/create-stuff-additions 。

`build_art.py` 与 `attachments.py` 使用项目 `scripts/concepts/render_scene.py` 生成实际立体投影。`attachments.json` 记录独立配件的尺寸、旋转、材质及所属身体部位，是离线概念格式，不是已接入的游戏模型。`textures/fittings.png` 为新配件材质，原护甲图集和四个物品图标延续 V3，物品图标暂未表达新增立体件。

模型尺寸以 Minecraft 模型像素为单位。保留本地概念稿，不修改正式资源、代码或注册；尚未验证游戏中关节动画和护甲渲染。
