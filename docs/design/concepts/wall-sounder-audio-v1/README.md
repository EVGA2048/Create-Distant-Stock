# 壁挂声光报警器 · 音效候选 V1

设备名称已确认：**红色声光报警器**、**橙色声光报警器**。外观基准为 `docs/design/accepted/wall-sounder-v4/`。

用户明确要求不要突然播放。此轮仅合成、保存、解码和数值检查文件，**没有播放音频，没有打开音频播放器或自动预览**。后续也应由用户主动试听，不自动播放。

## 三种候选

| 编号 | 设计方向 | 单次长度 | 起音 |
| --- | --- | --- | --- |
| A `a_soft_chime` | 柔和短铃，660 Hz 主音，少量快速衰减泛音；优先试听的方向 | 340ms | 55ms 渐入 |
| B `b_descending_pair` | 圆润双音，784 → 587 Hz 下行提示，避免上行警笛感 | 460ms | 两个音均 55ms 渐入 |
| C `c_low_signal` | 低音机械提示，440 Hz 主音与有限的整数泛音 | 320ms | 65ms 渐入 |

全部使用正弦成分直接合成，没有引用外部录音，没有尖锐噪声、敲击瞬态或持续扫频。末尾平滑收至零。以上是合成设计描述，未通过实际听音确认；是否明显、舒适，需结合用户设备与游戏环境试听判断。

两种灯色目前均可使用这些候选，没有擅自给红灯分配更尖锐的音色；选定后再决定是否共用。

## 文件与主动试听

- `manual_listen/*_preview.wav`：供用户主动打开。先静音 **2 秒**，然后共播放 **4 次**提示，起音间隔 **1.5 秒**，末尾留 1 秒静音。总长约 7.8–8 秒。
- `single_pulse/*.wav`：单次 PCM 母版，没有预留 2 秒静音。
- `single_pulse/*.ogg`：单声道 Vorbis 游戏接入候选，没有预留 2 秒静音。
- `audio_check.json`：时长、峰值、RMS、编码后解码检查与文件摘要。
- `generate_audio.py`：可复现合成脚本；不会调用任何音频播放工具。

采样率 48kHz、单声道，WAV 16-bit PCM。母版峰值统一 −20 dBFS，OGG 解码后约 −19.9 dBFS，无削波。文件电平不等于设备实际声压，试听仍由用户自行控制音量。

候选声音持续约 0.3–0.46 秒，视觉闪光保持已定稿预览的 0.10 秒；二者起点可以同步，声音随后自然衰减，下一次在 1.5 秒后开始。当前只提供音频文件，未接入游戏、未更改告警逻辑，也未与 GIF 合成自动播放视频。

## 复现

在仓库根目录执行 `python3 docs/design/concepts/wall-sounder-audio-v1/generate_audio.py`，依赖 NumPy 和 ffmpeg。脚本生成 WAV / OGG，解码 OGG 到内存做幅度检查，验证试听文件前 2 秒完全静音。它不进行播放。
