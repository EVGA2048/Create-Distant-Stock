# 以太校准棱镜 V1

16×16 的高级光学产物概念。中央为淡蓝透明多面棱镜，三只黄铜固定爪将其装入断开的校准环，底部是安山合金调节座、黄铜调节螺钉和一枚淡蓝校准刻点。

设计沿用 Minecraft 原版和 Create 的大色块、有限色阶与清楚轮廓；玻璃切面包含实际半透明像素。没有光束、光晕、漂浮粒子或魔法晶核。

- `assets/distantstock/textures/item/ether_calibration_prism.png`：16×16 RGBA 原图。
- `assets/distantstock/models/item/ether_calibration_prism.json`：透明物品模型候选。
- `preview.png`：浅色、深色背景和较小物品尺寸检查。
- `build_art.py`：Python/Pillow 可复现绘制脚本。

仅概念美术，未覆盖正式资源，也未修改物品注册。
