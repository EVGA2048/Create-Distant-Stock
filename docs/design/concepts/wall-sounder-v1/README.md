# 壁挂声光报警器 V1 · Python 贴图试稿

![设计页](wall_sounder_design_sheet.png)

按用户要求先制作贴图：小型壁挂消防声光报警器，上蜂鸣器、下红色或橙色灯罩。浅蓝灰金属外壳、三道声孔和黄铜分隔条延续项目工业风格。

## 原生像素尺寸

全部素材由 `build_art.py` 使用 Pillow 直接绘制。16×16 RGBA 画布，面板实际轮廓为 **8×12**，占据图像 x=4..11、y=2..13；正视布局约半格宽、四分之三格高。按 1 纹素/模型单位的比例为后续壁挂模型预留，没有增加高分辨率细节。

顶部为三道 4×1 声孔，底部为 6×4 有色灯罩。顶部声孔区域、分隔条与外壳不随闪烁改变。

## 文件

- `textures/sounder_red_off.png` / `sounder_red_on.png`：红色正面熄灯、亮灯贴图。
- `textures/sounder_orange_off.png` / `sounder_orange_on.png`：橙色正面熄灯、亮灯贴图。
- `textures/sounder_casing.png`：独立外壳及反光底板。
- `textures/lens_{red,orange}_{off,on}.png`：单独的半透明灯罩层，供后续模型使用。
- `wall_sounder_design_sheet.png`：放大贴图、两种灯色和节奏说明。
- `wall_sounder_preview.png`：静态双配色预览。
- `wall_sounder_pulse.gif`：**无声**节奏示意。
- `readability.png`：1×、2×、3×、4× 显示检查。

合成正面图为不透明外壳上的灯罩观感；真正半透明的灯罩素材另外分层交付。棋盘格和深色预览背景不在原始贴图里。

## 节奏与待制作音效

当前美术动画候选：**亮 100ms，灭 1400ms**，1.5 秒一轮，表示用户描述的“啪——啪——”。GIF 先展示熄灯状态再短闪，两种颜色同步仅为便于比较，不表示同一设备必须安装两盏灯。

用户同时提出后续需要新音效：清楚、容易注意到，但不制造焦虑或惊吓。制作方向记录为柔和短提示音、缓起音、短而自然的衰减；不把“啪”的节奏描述做成爆裂声，不采用尖锐警笛。具体音色、响度和间隔仍需制作并试听。本轮按“先画贴图”要求未制作音频。

## 复现与验证

仓库根目录运行：`python3 docs/design/concepts/wall-sounder-v1/build_art.py`。依赖 Pillow 与本机中文字体。

已检查 16×16 贴图、8×12 轮廓、状态像素变化只发生在灯罩区域，以及 GIF 1400/100ms 帧时长；已查看设计页。仅新增美术概念文件，未建立方块模型、注册、触发逻辑或游戏音效。
