# 声光报警器音效 V2 · 小扬声器失真与消防变调

适用名称：红色声光报警器、橙色声光报警器。外观确认稿为壁挂 V4。

用户选中了 V1 的 B 双音方向，但认为过于干净，要求低质扬声器的失真感；另外希望增加类似国内常见消防设备的周期变调方向。本轮生成四个对照候选，未最终定稿。

**用户要求不得突然播放。所有步骤仅生成文件、解码至内存并数值检查，未调用播放器，未进行音频播放或自动预览。所有试听文件都预留 2 秒静音，由用户主动打开。**

## 候选

| 名称 | 设计 | 音频长度 / 重复起点间隔 | 试听 |
| --- | --- | --- | --- |
| B1 `b1_small_speaker` | 保持 784→587 Hz 的原 B 双音，加入窄频、非对称软削波、共振及微量信号相关粗糙声 | 0.46s / 1.5s | 4 次，7.96s |
| B2 `b2_worn_speaker` | 同样双音，更强驱动失真、更窄高频及更明显的粗糙感 | 0.46s / 1.5s | 4 次，7.96s |
| F1 `f1_fire_sweep` | 慢升快降的消防风格扫频，约 760→1540→760 Hz，经过小扬声器处理 | 4.15s / 4.5s | 2 轮，11.65s |
| F2 `f2_fire_alternating` | 较短的高低交替，约 800↔1250 Hz，连续相位、平滑过渡，经过同类扬声器处理 | 1.12s / 1.5s | 4 次，8.62s |

B1/B2 使用 `reference/b_original.wav` 作为输入，保持原始双音音高与节奏。处理包括高低通、箱体共振、软过载、轻量量化、随信号出现的微量噪声；失真后再次高通去除直流偏置，并平滑收尾，没有故意加入开机爆音或点击声。

F1/F2 为原创风格合成，**没有使用海湾或青鸟的原机录音，也不声称复刻具体型号的音色或频率曲线**。F1 长周期与 B 的短周期是两种候选方案，不需要强制跟每次灯闪同周期；视觉仍沿用已确认预览的 100ms 亮 / 1400ms 灭。

## 厂家资料与设计依据

- [青鸟 JBF5174 使用说明书 V1.1](https://www.jbufa.com/uploads/20240911/01b85c193eb641d5688162906205c497.pdf)：列有火警声、滴滴滴声两种音调；第 2 页标注变调周期 4–5 秒。因此 F1 取 **4.5 秒一轮**，扫频曲线本身由本稿设计。
- [海湾消防系统产品手册](https://www.gst.com.cn/images/海湾火灾自动报警及消防联动控制系统产品手册Version202107.pdf)：列有部分声光警报器的火警声、滴滴声两种模式，用于确认这些设备存在不同音调选择，不据此推断具体声学波形。

原始要求中“不焦虑、不惊吓、但明显”的方向继续保留：起音渐入、有限高频、降低文件电平。实际听感未通过播放确认，需用户主动试听；这里记录的是合成设计和可测参数。

## 文件与检查

- `manual_listen/*_preview.wav`：带 2 秒起始静音、重复节奏和 1 秒尾部静音，仅供用户手动试听。
- `single_cycle/*.wav`：单次 PCM 母版，没有起始 2 秒静音。
- `single_cycle/*.ogg`：单次游戏资源候选，没有起始 2 秒静音。
- `audio_check.json`：时长、重复周期、峰值、RMS、偏置、OGG 摘要。
- `generate_audio.py`：合成脚本，无播放调用。

48kHz 单声道，WAV 为 16-bit PCM。四种候选的片段 RMS 均控制为 −30 dBFS，峰值低于 −20 dBFS，避免长扫频仅因持续时间更长而获得明显更大的平均电平；这不等于主观响度完全一致。实际峰值见检查报告。

已验证起始静音、首尾零点、峰值、RMS、直流偏置及 OGG 编码后解码数据。没有进行主观试听。依赖 NumPy、ffmpeg，在仓库根目录执行 `python3 docs/design/concepts/wall-sounder-audio-v2/generate_audio.py` 复现。

用户后续确认：这几种音效都可以保留。四种原版音频原样留存；F1 下降段“颤了一下”的反馈另见 [V3 修订](../wall-sounder-audio-v3/README.md)，待试听确认。本轮未替换已存在的游戏音效、未修改音效注册，也未将音频绑定到红色或橙色设备。
