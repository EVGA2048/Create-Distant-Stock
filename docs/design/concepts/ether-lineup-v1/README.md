# 以太设备线 V1 · 外观重设计概念

本目录是远仓请求台、互通塔耦合器、以太谐振器、远仓日志台、辉光管时钟、翻牌时钟的重设计，以及新的高阶产物谐振以太晶体。全部为离线概念稿：没有修改 `src/main/resources` 下的任何正式资源，也没有改动代码。

设计原则：
- 机身只用 Create 原版贴图，即安山机壳、黄铜机壳、黄铜块和工业铁块。
- 以太部分统一使用现有以太石英的色阶。以太在设备上用三种形式出现：玻璃柱、芯条和指示灯。
- 所有方块都由 Minecraft JSON 元素构成，坐标限制在 -16..32 以内，旋转只用 ±22.5° 或 ±45°，可以直接作为方块模型接入。

## 图纸

| 文件 | 内容 |
|---|---|
| `tower_sheet.png` | 互通塔新旧对比（旧版 / 新版待机 / 新版运行），以及耦合器和谐振器特写。耦合器由四角安山立柱、黄铜箍和以太玻璃柱组成；谐振器是带调谐叉的黄铜转子，顶上是 45° 的以太发射晶体，运行时转子转 22.5° 并向上射出光束。 |
| `console_sheet.png` | 请求台：铁质底座、斜面屏幕显示库存行，黄铜顶罩带三个按键，背后的天线顶端是以太宝石。日志台：安山背板、打印机吐出小票，两支辉光管加三色状态灯。两者各附现有外观对比。 |
| `clock_sheet.png` | 辉光管时钟和翻牌时钟采用同一套壁挂外形，都是四位数字加中间两点，顶部的以太同步灯表示时间来自远仓网络。辉光管版：黄铜框、工业铁背板、玻璃管。翻牌版：安山机壳、深色翻牌加铁合页。 |
| `crystal_sheet.png` | 谐振以太晶体：16×16 物品图标、物品栏实际尺寸预览、安山加黄铜三爪展示座的 3D 渲染，以及材料阶梯（以太石英 › 磨制以太石英 › 以太构件 › 谐振以太晶体）。 |

`models/` 是可直接参考的方块模型 JSON，其中 `concept:*` 贴图对应 `textures/` 里的同名文件。`renders/` 是单独的渲染图。

## 说明

- 翻牌时钟已在本轮修复中从代码里移除。这里只提供外观方案，要恢复需要重新实现方块和渲染器。
- 谐振以太晶体图标完全不透明，颜色全部取自以太石英和黄铜色阶。按 V4 被否定时的反馈，没有加发光核心、光晕或三角玻璃轮廓。3D 展示座使用自定义三角面，接入游戏时需要改为物品模型或方块元素。
- 合成定位只是建议，未实装：以太构件加黄铜，在运行中的以太谐振器上做序列组装。
- 已用数值方式检查：
  - 渲染范围都在画面内。
  - 时钟数字从正视图解码，读数为 12:45，排列方向正确。
  - 晶体 12 个切面和腰箍的法线都朝外。
  - 图标没有色板以外的颜色。
- 图像本身未经人工目视检查，请以实际观感为准。

## 复现

```sh
cd docs/design/concepts/ether-lineup-v1
python3 -B build_tower.py && python3 -B build_consoles.py && python3 -B build_clocks.py && python3 -B build_crystal.py
```

依赖 `scripts/concepts/` 下的渲染器和 Create 6.0.10 jar（可用 `CREATE_JAR` 指定路径），以及 `build/moddev/artifacts` 里的原版资源 jar。`build_clocks.py` 会用到 `build_tower.py` 生成的 `textures/ether_core.png`，所以要按上面的顺序运行。
