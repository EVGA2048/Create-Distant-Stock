# F1 下降段修订

用户确认 V2 四种音效都可以保留，但反馈 F1 下降时颤了一下。本版仅新增 F1 修订，V2 的 B1、B2、F1 原版、F2 音频全部原样保留，已通过 SHA256 比对。

延续 760→1540→760 Hz 的扫频及原有小扬声器失真链。第三次修订把扫频改为接近对称：0.30–1.95 秒上升、1.95–3.60 秒下降，两段均为 1.65 秒，避免旧版约 2.7 秒缓慢上升后仅用约 0.85 秒快速下降的“突然掉下去”听感。音调斜率转折继续平滑，下降段继续补偿缓慢的电平凹陷和回升。尾音在下降尚未结束时即开始释放：3.46 秒进入 raised-cosine 淡出，3.62 秒后保持数字静音，不再保留最低频平台，也不做硬门限切断。没有去掉破音、共振、窄频和粗糙质感。

原版下降主段（3.05–3.82 秒）40ms 窗口 RMS 起伏约 3.019 dB；修订母版为 0.064 dB，OGG 解码后为 0.099 dB。下降主段的设计频率单调下降、相位连续；尾音在扫频触底后立即进入平滑衰减。上述为数值检查，不能代替用户最终听感确认。

- [手动试听](manual_listen/f1_fire_sweep_smooth_preview.wav)：开头 2 秒静音，2 轮，总长 11.65 秒。
- `single_cycle/f1_fire_sweep_smooth.wav`：4.15 秒单次母版。
- `single_cycle/f1_fire_sweep_smooth.ogg`：单次游戏资源候选。
- `audio_check.json`：电平、下降段起伏、原版音频校验摘要。

48kHz 单声道；WAV 为 PCM16；RMS −30 dBFS，峰值约 −24.39 dBFS。未播放、未自动打开播放器，也未接入游戏。只向用户提供普通文件链接。
