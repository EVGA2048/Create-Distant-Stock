# 谐振装备维护座 V1

远仓护甲充气/维护设备概念稿。目标是把两种补能方式合在同一个可放置组件中：

- **机械快充**：侧面接入 Create 旋转轴，转速越高充气越快。
- **塔网涓流**：位于运行中的远仓塔覆盖范围内时，顶部谐振节点可在无轴输入时极慢补能。

设备占地约 1×1 格，高约 1.5 格。胸甲挂在中央维护架，正面状态窗显示气量与链路状态。美术沿用远仓塔机壳、黄铜、铁件和以太晶体的既有材质；青白粒子只表示补能过程，不是常驻光效。

`build_art.py` 使用项目 `scripts/concepts/render_scene.py` 离线渲染。概念稿不修改正式方块、注册或游戏逻辑。
