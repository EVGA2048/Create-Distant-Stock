# 谐振石英护甲物品图 V1

依据当前 `scripts/gen_ether_armor.py` 的磨制石英透明壳体设计，保留钻石护甲的四种原版轮廓。颜色使用该脚本的八色以太石英色阶。

四张原生 16×16 RGBA 图：头盔、胸甲、护腿、靴子。亮磨边、凹入边缘、浅蓝侧面与局部斜反光表现石英壳体；大面保留有限透明度，较穿戴模型更实，以维持背包中的可辨识度。没有额外机械饰件。

仅独立美术方案，未替换生产贴图。文件沿用当前物品资源名以便后续使用。

`python3 build_art.py` 重建。`preview.png` 和 `preview_dark.png` 为两种底色预览；`inventory_scale.png` 为 2 倍物品栏大小预览。
