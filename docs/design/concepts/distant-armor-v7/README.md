# 谐振石英护甲 V7 · 磨制石英 / 半透明

概念稿。**未接入模组**，`src/main` 一个字节都没改。

V6 是在 V5 的机壳语言里改。V7 不是——**换掉整套材质语言，并且做成半透明。**

---

## 一、半透明：能不能做

**能，而且不用写新代码。** 项目里已经有这条渲染路径：

`HumanoidArmorLayerMixin` 把 `textures/models/armor/ether_casing_layer_` 开头的贴图
强制成 `entityTranslucent`。**原版护甲是 `cutout`——alpha 当二值用**，写 40 和写 255 长得一样；
强制成 translucent 之后 alpha 才是真正的混合系数。

隐身那 13 张相位贴图就是靠这条路在淡出的，所以这套渲染管线在本项目里**已经跑通了**。

### 做法

不是给实体版贴图加个 alpha 就完事——**透明的东西靠棱和边读出来，不靠面**。
直接加 alpha 只会得到一层雾。所以覆盖度由「这个格子有多结构」决定：

| | alpha |
|---|---|
| 平板甲面（占绝大多数） | **40** ← 几乎全透，皮肤直接透出来 |
| 倒角棱线 | 40 + 0.7×90 ≈ **103** |
| 甲片收边（下摆/袖口/靴口） | ≈ **157** |
| 天面镜面 | **235** |

面 alpha 和棱增益是两个独立旋钮（`ALPHA_FACE` / `ALPHA_GAIN`），
`glass_levels.png` 里渲了极透(26) / 很透(40) / 偏实(66) 三档。**当前档平均 alpha ≈ 85/255。**

另外：**玻璃的色被顶在色阶的亮端**（`GLASS_FLOOR`）。深色 tint 盖在皮肤上不读成玻璃，读成脏。

### 实装前必须验的三件事

1. **内侧面的重复混合。** 每个 armor cuboid 六个面都会画，所以你会透过胸口正面看到胸甲内侧。
   这正是「玻璃壳」该有的样子，但也可能糊。**这条离线渲不出来，必须进游戏看。**
2. **和其他半透明物的排序**（水、玻璃方块、以及潜行时的自己）。
3. **贴图必须叫 `ether_casing_layer_*`**，否则 mixin 不认，直接掉回 cutout，alpha 全部失效。
   概念稿里叫 `v7_layer_*`，实装时要改名。

### 和现有系统的衔接

- **隐身相位**：现在是 255→0 淡出。基础 alpha 变成 ~40 之后，淡出要从玻璃 alpha 出发，
  `gen_ether_armor.py` 的相位生成要跟着改。**不改的话一潜行会先「变实」再淡出。**
- **翅膀** 13 张同理。

## 二、材质：直接用磨制以太石英的八个色

`polished_ether_quartz.png` 是一张 113 像素、**8 个颜色**的图。这八个色，从暗到亮，原样拿来用：

`#35536E`(78.6) `#507B9B`(116.2) `#699DBC`(148.2) `#8DBBD6`(179.2)
`#B6D8E8`(209.9) `#D9EBEE`(231.4) `#F3F6E9`(244.4) `#FFFFFF`(255.0)

**一个都不加、一个都不减。**

> 早先那版我在暗端**私自补了两档**（明度 51、73），想让对比强一点。
> 结果整件甲比它自己用的材料还暗两整档——这就是「哪不对」的一半。

原石版和磨制版**是同一组八色**，只是配比不同：磨制版重心压在 `#699DBC` 和 `#F3F6E9`，所以更白。
**用磨制那颗当参考是对的。**

## 三、参考从哪来

| 参考 | 颜色数 | 做法 |
|---|---|---|
| 原版 钻石 / 铁 | 7~10 | 近乎平涂 |
| **Create 铜潜水服** | **52** | 每个局部自带明暗 |
| Create 下界潜水服 | 20 | 同上 |

**关键不是颜色数，是边界。** 铜潜水服胸口面 dump 成像素：

```
     01234567
 20  oo++##++++##++oo
 21  oo++++++++++++oo
 22  ==oooo++++oooo==
```

左右两列是**中间调**不是深色，深色只在**中间的横向绑带**上。
**Create 不给甲面描边框**——它把整件甲当一个连续物体画。我前两版都在描边，方向就错了。

## 四、着色

```
f = 朝向基调 + 倒角 + 肩 + 面内渐变 − 收边
```

1. **朝向定基调** `{up:6, north:4, west:4, east:3, south:2, down:1}`
2. **倒角**：朝上/朝左 +0.7、朝下/朝右 −0.7，**按边数求和**（角上能到 ±1.4）
3. **肩**：倒角内侧一格再缓 0.3
4. **面内斜向渐变** ±0.9
5. **收边**：胸甲下摆、袖子收口、靴口靴底

## 五、过渡怎么写

连续值怎么落到颜色上，决定过渡自不自然。`transition_compare.png` 里三条路都渲了：

| | 做法 | 结果 |
|---|---|---|
| A | 硬量化到八个极点 | 每档之间**硬边** |
| B | 4×4 Bayer 抖动 | 硬边化开，但卡在半档的像素 50/50 破开，**迷彩噪点** |
| C | **八极点插值成 25 档，直接量化** | **无色带也无噪点** ← 采用 |

根因是**色阶太粗**：一个甲面只跨两三档，而八档之间每档差很远。插值不引入新色相。

## 六、收边：让它读成护甲而不是紧身衣

去掉胸口元素后，整件甲从领口到脚底完全贴体，**读成了紧身衣**。补的不是装饰，
是**甲片自己的厚度**——最下一行翻进去压得最深，上一行少接一点光。
`plate_compare.png` 里有/无并排；`PLATES = False` 可关。

## 七、胸前不加任何元素

胸口**完全留白**。V5 那枚 2×2 小窗、V7 前版的竖长条介质池都删了。
唯一的亮点是**天面的一小段镜面**（头盔顶、肩头），那是「磨制」该有的高光。

## 九、没做的 / 待定

- **物品图标还是实体版。** 半透明的背包图标可能读成「缺失/损坏」，要不要跟着透是个决定。
- **相位贴图（隐身 13 张 + 翅膀 13 张）没有重做。** 半透明之后它们的淡出逻辑必须跟着改，
  否则潜行时会先变实再淡出。**这是实装前的第一件事。**
- **没进过游戏。** 内侧面的重复混合、与其他半透明物的排序，都只能进游戏才验得了。
- 护腿和靴子仍然没有独有能力。
