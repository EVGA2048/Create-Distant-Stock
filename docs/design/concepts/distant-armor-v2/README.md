# 远仓机壳护甲 V2

按用户要求回归简洁、明亮的远仓机壳材质与钻石护甲外形。两张 64×32 原版护甲 UV 图集和四张 16×16 物品贴图保持钻石护甲的透明覆盖范围及原有明暗结构；换用浅蓝灰、冷钢灰与温白色阶，并少量融入机壳中心纹素变化。

去除上一稿的分片甲、黄铜扣件、深色关节、护目镜。穿戴效果使用项目 scripts/concepts/render_scene.py 绘制，灰色内衬与人台头部仅用于展示，不属于护甲。基于原版外层 1、内层 0.5 的膨胀量；离线预览手臂为 0.96、腰部为 0.48，避免相交面深度冲突。展示站姿略分开，防止鞋边相交。

运行 `python3 docs/design/concepts/distant-armor-v2/build_art.py` 可复现。已逐像素核对全部 Alpha 与原版源图一致。仅概念文件，未改正式资源、模型或注册；未接入游戏。
