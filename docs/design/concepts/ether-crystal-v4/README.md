# 以太晶体 V4 · 透明棱镜

按用户修正重新设计：接近原版与 Create 的小色块、明确切面思路，并体现光学棱镜。回到直接绘制的 16×16 像素，不沿用 V3 高分辨率生成稿。

主体为两个全等三角形截面构成的短三棱柱，淡蓝色大平面、选择性的浅色棱线与一条隐约可见的后棱。不含发光晶核、蓝紫渐变或散落光点。玻璃主面 Alpha 为 112 和 157，轮廓约 213–238，上部少量高光接近不透明；有实际半透明像素。

- `assets/distantstock/textures/item/ether_crystal.png`：16×16 RGBA 原图。
- `preview.png`：同一贴图在浅、深背景的合成预览及 2 倍物品大小示意。
- `transparency_check.png`：棋盘格透光检查。
- `build_art.py`：Python/Pillow 像素绘制及检查脚本。

仅新美术候选，旧稿保留，未覆盖正式资源或修改模型。游戏接入时需要支持半透明物品的渲染路径，当前为离线透明度预览。
