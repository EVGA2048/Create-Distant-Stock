原图：`assets/distantstock/textures/item/resonant_sturdy_sheet.png`，16×16 RGBA、透明背景。像素位置和 Alpha 与 Create 原贴图完全相同。原始纹理来源 Create 6.0.10，后续使用遵循项目既有素材许可约定。

运行 `python3 docs/design/concepts/resonant-sturdy-sheet-v1/build_art.py` 可复现。仅独立美术稿，未覆盖正式资源或注册新物品。
