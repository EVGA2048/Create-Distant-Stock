# 中文物品说明风格

物品说明采用简洁、客观的设备说明语言，与 Create 的条件式提示结构一致。

- 概述说明用途及必要限制；操作条件与效果分别写入 `conditionN` 和 `behaviourN`。
- 使用“接收、发送、绑定、装填、注入、消耗、装备”等直接描述功能的动词，避免拟人化、对玩家说话或宣传式措辞。
- 不使用“替你挡下、喂来的数据、念给玩家听、喝一口、装得下”等口语表达。
- 同类物品共用操作措辞；沿用 Create 的中文物品名称，如“工程师护目镜”“分液池”。
- 属性数值、单位、触发条件和限制必须与实现一致。语言润色不改变玩法承诺。
- `_关键词_` 用于 Create 高亮，必须成对；Lore 中的百分号写作 `%%`，保留 `%s`、`%1$s`、`{1}` 等格式参数。
