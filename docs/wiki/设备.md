# 设备

这一页按设备的实际职责说明。

---

## 便携式远仓终端

`distantstock:requester`

远仓最常用的配置工具和便携请求终端。

它可以：

- 创建或加入正式远仓网络；
- 在当前远仓网络的成员仓库之间切换；
- 查看库存并提交订单；
- 选择接收港地址；
- 设置 Create 包裹地址；
- 把远仓网络上下文复制给请求台、仪表和红石请求器；
- 在远仓港处把本地 Create 仓库加入当前远仓网络。

### 一个重要变化

全新的终端不再先显示“本服所有 Create 仓储网络”。

正确顺序是：

```text
先创建 / 加入远仓网络
→ 再通过远仓港收编本地 Create 仓库
→ 仓库列表只显示该远仓网络的成员
```

### 操作

- **右键空气**：打开终端；
- **潜行 + 右键空气**：清除终端当前网络相关绑定，包括远仓网络上下文、成员仓库和接收港组；已经填写的 Create 包裹地址字段会保留；
- **右键已绑定 Create 网络的远仓港**：加入仓库、选中仓库或配置发送方向；
- **潜行右键远仓港**：在仓库已经属于同一远仓网络后，把港加入当前接收港组；
- **右键远仓仪表 / 红石请求器**：把终端所在远仓网络作为本地快捷配对来源。

## 远仓请求台

`distantstock:gauge`

固定式请求终端。

新放下的请求台没有 Create 仓库，也没有正式远仓网络上下文。

手持已经加入远仓网络的便携终端右键请求台：

- 如果终端只加入了远仓网络、还没选择仓库：请求台先获得该远仓网络上下文，仓库保持未选择；
- 如果终端已经选中成员仓库：请求台同时复制当前仓库、包裹地址和接收港组。

之后请求台的仓库选择器只显示**这张远仓网络的成员仓库**。

### “阻止其他玩家从此处下单”

请求台界面在选中**本地** Create 仓库时，会显示 Create 原生物流网络锁定控制。

它实际修改的是 Create `LogisticsNetwork.locked`，所以语义与 Create 原版 Stock Keeper 一致：

- 只有有 Create 管理权限的玩家能切换；
- 锁定后普通非 owner 玩家不能通过这张 Create 网络下单；
- 这是整张 Create 物流网络的锁，不是只锁这一台远仓请求台；
- 便携式远仓终端不会成为远程修改 Create 锁定状态的管理员开关。

## 远仓打包机

`distantstock:remote_packager`

Create 打包机的远仓变体。

它负责把远仓订单实际变成 Create 包裹，并送入本地物流与远仓港。

如果订单已经抵达来源服务器，但远仓港一直没有收到包裹，应优先排查远仓打包机和本地 Create 包裹路线。

## 远仓港

`distantstock:dock`

跨服包裹真正进入或离开远仓运输层的端口。

### 第一步：先绑定 Create 网络

拿着**远仓港物品**右键本地 Create 物流链接，然后再放置。

这样港才知道自己属于哪张 Create 仓储网络。

### 第二步：把整张 Create 仓库加入远仓网络

拿着已经加入正式远仓网络的便携终端右键港。

如果港背后的 Create 网络还没有正式 membership：

- 服务端检查玩家对该 Create 网络的管理权限；
- 成功后把整张 Create 仓库加入终端所在的远仓网络；
- 自动生成成员仓库名称；
- 终端自动选中该仓库。

加入的是**Create 仓库**，不是单独这一台港。

同一张 Create 网络下再放第二台、第三台远仓港，不需要重复建立新的 membership。

### 已经入网后的普通右键

终端和港已经处于同一远仓网络时，普通右键用于：

- 选中港对应仓库；或
- 把港切到发送方向；
- 写入当前目标节点与接收港组。

### 潜行右键

把港加入终端当前选择的接收港组，并切到接收方向。

### 回退面

远仓港底面是回退出口。不能发送、需要退回本地物流的包裹会优先从这里离开。

正式工厂建议给回退面接独立箱子、保险库或报警检测，不要长期堵死。

## 远仓仪表

`distantstock:remote_gauge`

Create 工厂仪表的远仓版本，用于按目标库存自动向远程成员仓库补货。

### 先加入远仓网络

支持两种方式：

**A. 8 位加入码**

在仪表 UI 输入 `XXXX-XXXX` Join Code。这个方式不依赖玩家把终端带到另一台服务器，因此适合跨服配置。

**B. 便携终端本地配对**

拿一台已经加入远仓网络的便携终端右键仪表对应面板格。

- 终端只加入了远仓网络、没选仓库：仪表只复制远仓 network UUID；
- 终端已经选中成员仓库：仪表同时复制该来源仓库和终端携带的接收港组 / 包裹地址。

### 再选来源仓库

如果 B 方式没有顺手带入来源仓库，或使用的是加入码 A 方式，仪表入网以后再从 UI 选择。来源列表只包含这张远仓网络的成员仓库。

每个四分格面板槽都可以独立保存：

- 远仓网络；
- 来源成员仓库；
- 目标物品；
- 本地库存目标；
- 在途订单量；
- 接收港组和 Create 包裹地址。

本地成员仓库仍受 Create `mayInteract` 权限约束。

## 远仓红石请求器

`distantstock:remote_redstone_requester`

以 Create 红石请求器为基础的远程版本。

配置顺序和远仓仪表一致：

1. 用 8 位加入码，或便携终端右键，让设备加入远仓网络；
2. 如果终端已经选中成员仓库，本地配对会直接复制该来源；否则在 UI 中从该网络的成员仓库里选择；
3. 配置九个物品槽、接收港组和 Create 包裹地址；
4. 红石上升沿触发一次请求。

未建立远仓绑定时，它仍保留 Create 红石请求器的本地行为。

潜行配对操作可清除远仓来源绑定。

## 远仓监视器

`distantstock:monitor`

控制室实时状态设备。

### 方块正面的翻牌显示

当前版本使用 Create 自己的 Flap Display 机制，单方块高度原生为 **2 行**。

监视器每约 5 秒轮换一页：

- `TPS`：本服 TPS；
- `MSPT`：本服 MSPT；
- `PING`：对端 RTT；
- `BACK`：订单 + 包裹 backlog；
- `PEER`：最近收到的对端 TPS；
- `DEV`：当前绑定 Create 网络的设备数量。

左侧状态灯按本服 TPS 显示绿 / 橙 / 红；右侧链路灯区分：

- OFF；
- ONLINE；
- SYNCING；
- FAULT。

### 右键界面

空手右键打开完整监控界面，包含：

- 本机与对端 TPS / MSPT；
- RTT；
- 在线节点数量；
- 订单队列；
- 包裹队列；
- in-flight 数量；
- 失败计数；
- 互通塔成员、速度、应力、区块加载半径、以太和流量信息。

手持已经选中仓库的便携终端右键监视器，可以指定它统计的 Create 网络。

**当前版本监视器还没有把日志台 EventRegistry 告警直接显示到翻牌屏。** 两者目前是互补设备，而不是同一套显示器。

## 远仓日志台

`distantstock:logger`

远仓的事件记录、告警和打印终端。

日志台物品在放置前需要先右键一个 Create 物流链接，保存要监控的本地网络身份。

新放置日志台纸量为 `0 / 16`，因此默认就是缺纸状态 `PE`，不会显示假 `OK`。

完整状态码、蜂鸣器和小票行为见：[监控与日志](监控与日志.md)。

## 工况灯与工况链接器

`distantstock:stack_light`  
`distantstock:condition_linker`

三色工业工况灯。

工况链接器把附近红石状态无线送到已绑定工况灯：

- 红；
- 黄；
- 绿；
- 蜂鸣器使能。

红灯 + 蜂鸣器使能会周期报警；黄/绿上升沿各提示一次。

需要闪灯时，应在输入侧用 Create 脉冲计时器等红石逻辑实现，工况灯不会自己替你生成闪烁节拍。

---

## 独立信号灯与信号面板

远仓提供青、橙、红、绿、白等固定颜色信号灯与黄铜信号灯。

它们可以单独贴在方块表面，也可以进入四分格面板，与 Create 工厂仪表和远仓仪表混装。
