# 设备

这一页按设备的实际职责说明，不按创造栏顺序罗列。

---

## 便携式远仓终端

`distantstock:requester`

远仓最常用的设备，也是其它机器的主要配置工具。

它可以：

- 浏览本地和远端仓库；
- 查看远程库存；
- 提交跨服订单；
- 选择接收港地址；
- 设置包裹地址；
- 创建、加入和退出远仓网络；
- 把当前网络绑定复制给其它远仓设备。

### 操作

- **右键**：打开终端；
- **潜行 + 对空气右键**：清除当前网络绑定。

终端绑定网络以后会出现附魔光效，并在物品信息中显示当前仓储网络。

## 远仓请求台

`distantstock:gauge`

固定式的仓储请求终端。

**新放下的请求台没有任何 Create 网络或远仓网络绑定。** 打开界面时可以看到本服可用的 Create 仓储网络，但“发现到”不等于“已经绑定”；只有显式选择/复制绑定以后，请求台才获得仓库上下文，并实时继承那张 Create 网络所属的远仓网络。

功能与便携式远仓终端的下单部分相近，适合做在仓库、车间或控制室里。

手持已经绑定的便携式远仓终端右键请求台，可以把终端当前的：

- 仓储网络；
- 包裹地址；
- 接收港地址

写入请求台。

空手右键打开请求界面。

## 远仓打包机

`distantstock:remote_packager`

Create 打包机的远仓变体。

它负责把仓储订单生成的货物包装成能进入远仓运输流程的包裹。

远仓打包机仍然属于 Create 的包裹物流体系。它不是存储设备，也不直接负责服务器连接。

如果远仓订单已经到达来源服，但没有包裹进入远仓港，应优先检查这一段本地物流。

## 远仓港

`distantstock:dock`

跨服包裹真正进入或离开远仓运输层的端口。

一个港可以工作在发送、接收或双向模式，并带有独立缓存。

### 发送方向

来源端包裹进入港以后，远仓港读取包裹路线，将它交给远仓运输层。

手持已配置的便携式远仓终端**普通右键**远仓港，可以：

- 将港切到发送方向；
- 设置默认目的节点；
- 设置默认接收港地址。

### 接收方向

手持终端**潜行右键**远仓港，会把这个港加入终端当前选择的接收港地址，并切到接收方向。

接收港只负责决定“包裹从哪组港落地”。包裹离开港以后，仍然保留它自己的 Create 包裹地址。

### 回退面

远仓港底面是回退出口。

无法继续发送、找不到目的地或需要退回本地物流的包裹会优先从这里离开，而不是消失。

建议在正式工厂里给回退面单独接：

- 箱子；
- 保险库；
- 传送带；
- 报警检测。

不要把回退面堵死后长期不管。日志系统会把持续堵塞记为告警。

### 护目镜

工程师护目镜可以查看港的模式、网络、接收港地址、缓存和故障信息。

## 远仓仪表

`distantstock:remote_gauge`

Create 工厂仪表的远仓版本。

它的用途不是“显示远端还有多少”，而是让本地工厂按目标库存自动从远程仓库补货。

仪表会记录：

- 远端货源；
- 当前本地库存；
- 目标库存；
- 已下单但还在途的数量；
- 接收港地址。

当本地数量低于目标值时，它会按缺口下单；已在途的数量会计入计算，避免同一批货因为延迟而被反复下单。

单次订单上限由服务器配置 `remoteGauge.orderStacks` 控制，默认 1 组。

### 四分格面板

远仓仪表可以和其它工厂仪表、远仓信号灯混装在 Create 风格的四分格面板上。

每个格子的绑定、目标和在途数量独立计算。

## 远仓红石请求器

`distantstock:remote_redstone_requester`

以 Create 红石请求器为基础的远程版本。

界面、九个物品槽、地址输入和红石触发方式沿用 Create；区别在于绑定远程仓库以后，红石上升沿会向远端下单。

- 一次上升沿只产生一笔请求；
- 绑定远仓以后，需要互通塔带载；
- 未绑定时，它仍然按普通 Create 红石请求器工作。

手持已绑定的便携式远仓终端右键可指定远端货源；潜行右键可解除远仓绑定。

## 远仓监视器

`distantstock:monitor`

控制室用状态设备。

它用于查看：

- Transerver 链路；
- 本服与远端节点状态；
- 当前网络；
- 互通塔；
- 区块加载；
- 带载设备；
- 最近流量等信息。

手持已绑定的便携式远仓终端右键监视器，可以指定监控的仓储网络。

空手右键打开界面。

管理员潜行打开时还可以进入服务器侧配置页面。

---

## 远仓日志台

`distantstock:logger`

远仓的事件记录、告警和打印设备。

和监视器不同，它关注的不是“现在有多少库存”，而是：

> 系统发生过什么异常，现在还有哪些问题没有处理？

日志台必须先绑定一张已有的 Create 物流网络，再放置。

详细行为见：[监控与日志](监控与日志.md)。

## 工况灯与工况链接器

`distantstock:stack_light`  
`distantstock:condition_linker`

三色工业工况灯。

工况链接器把附近红石状态无线送到已绑定的工况灯：

- 红；
- 黄；
- 绿；
- 蜂鸣器使能。

三种灯可以独立同时点亮。

蜂鸣器使能开启时：

- 红灯亮起后按固定节拍报警；
- 黄灯或绿灯出现上升沿时，各提示一次。

工况灯自己不生成闪烁逻辑。需要闪灯时，推荐在输入侧使用 Create **脉冲计时器**；需要延长亮灯时间时再接 **脉冲延长器**。

## 独立信号灯与信号面板

远仓提供青、橙、红、绿、白等固定颜色信号灯，以及黄铜信号灯。

它们既可以单独贴在方块表面，也可以安装进四分格信号面板，与 Create 工厂仪表混装。

这一套更适合做：

- 车间状态灯；
- 物流到货指示；
- 网络状态；
- 工位呼叫；
- 控制室面板。
