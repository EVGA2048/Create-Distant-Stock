# 快速开始

这一页只做一件事：让两台已经安装远仓的服务器完成第一笔跨服订单。

> 以下步骤默认服务器管理员已经把 Transerver 配好，两端可以互相通信。

---

## 1. 两边先有能工作的 Create 本地物流

来源端至少需要：

- 一张 Create 仓储网络；
- 仓储链接与物流链接；
- 能正常生成本地订单包裹的物流；
- 一台远仓打包机；
- 一台远仓港。

接收端至少需要：

- 一台远仓港；
- 能把包裹从港口继续送走的本地 Create 包裹物流。

如果 Create 自己连本地订单都不能完成，先修本地系统，再接远仓。

### 先给远仓港绑定 Create 网络

拿着**远仓港物品**右键要接入的 Create 物流链接。绑定成功后再放置远仓港。

这个动作只是在说：

> 这台港属于哪张本地 Create 仓储网络。

它还没有把这张仓库加入任何远仓网络。

---

## 2. 建互通塔

一座最小互通塔需要：

1. **互通塔底座**；
2. 底座正下方输入旋转动力；
3. 至少 **5 个互通塔耦合器**连续向上；
4. 最顶端放置 **以太谐振器**。

5 个耦合器为 I 级塔。I 级塔可以带载 8 台远仓设备，设备覆盖半径为 32 格。

底座只从**下方**接受旋转动力。

详细结构见：[互通塔](互通塔.md)。

---

## 3. 先让便携终端加入远仓网络

这一步现在发生在“选择 Create 仓库”之前。

第一台服务器：

1. 打开一台全新的**便携式远仓终端**；
2. 进入远仓网络页面；
3. 创建网络，例如 `Elysium`；
4. 记录生成的 8 位加入码，例如 `AB3D-7K2M`。

此时终端已经属于 `Elysium`，即使还没有选择任何 Create 仓库也是合法状态。

第二台服务器：

1. 打开另一台全新的便携式远仓终端；
2. 输入第一台服务器给出的加入码；
3. 等待加入完成。

加入其它节点创建的网络需要 Transerver transport 在线；加入码恰好属于本机创建的网络时可以本地完成。

**加入码只是授权凭证，不是 UUID。** 成功加入后，终端保存的是正式远仓网络身份。

---

## 4. 把两边的 Create 仓库收进远仓网络

现在拿着已经加入 `Elysium` 的便携终端，走到本地那台已经绑定 Create 网络的远仓港旁边。

**普通右键远仓港。**

如果这张 Create 仓库还没有正式远仓 membership，这次点击会优先执行：

```text
当前 Create 仓储网络
        ↓
加入终端所在的 Elysium
```

这个动作要求玩家拥有 Create 对该本地物流网络的**管理权限**。

成功后：

- 这张 Create 仓库成为 `Elysium` 的正式成员；
- 终端自动选中这张仓库；
- 系统为它生成一个默认人类可读名称，例如 `玩家名 的仓库`；
- 之后可以在远仓网络页面改名。

在第二台服务器重复一次。

### 为什么不从列表里选？

因为公共服里可能有几十甚至几百张玩家 Create 网络。远仓不会把它们全部公开给客户端。

终端的仓库列表只显示**当前远仓网络已经登记的成员仓库**。

---

## 5. 建一个接收港地址

第一条线路只需要一个接收港地址，例如：

```text
Main
```

接收港地址只在当前远仓网络内有效。另一张远仓网络也可以有自己的 `Main`，二者不会串包。

在接收端终端中选中 `Main`，然后**潜行右键接收端远仓港**。

这表示：

> 这个港属于 `Main` 接收组，并切到接收方向。

同一个接收地址以后可以挂多台港，实现并行与冗余。

---

## 6. 配置发送端远仓港

回到来源端。

确保终端：

- 已经在正确的远仓网络；
- 已经选中来源仓库；
- 已经选中目标接收港地址，例如 `Main`。

再次**普通右键**已经完成 membership 的远仓港。

这次点击会把港切到发送方向，并写入默认目的节点和接收港组。

> 对一张刚刚第一次接入远仓网络的仓库，第一次普通右键可能只完成“收编仓库”；再点一次才进入发送配置。这是两个不同动作。

工程师护目镜可以查看港的模式、绑定网络、接收港组、缓存和故障状态。

---

## 7. 接入远仓打包机

远仓打包机负责把来源仓库订单变成远仓运输的包裹。

它仍属于 Create 包裹物流的一部分，不是“跨服箱子”。

第一次联调时，先确认来源仓库收到订单后，包裹真的进入发送端远仓港。

如果包裹根本没到港，问题还在本地 Create 物流，不在 Transerver。

---

## 8. 从另一端下第一笔订单

现在回到接收服务器，打开便携式远仓终端：

1. 在仓库列表中选择 `Elysium` 的来源成员仓库；
2. 选择一个来源仓库确实存在的物品；
3. 设置数量；
4. 选择接收港地址 `Main`；
5. 如有需要，设置 Create 包裹地址；
6. 提交订单。

流程应当是：

```text
接收端提交订单
  ↓
来源端 Create 仓库处理订单
  ↓
远仓打包机生成包裹
  ↓
发送端远仓港
  ↓
Transerver
  ↓
接收端 Main 港组
  ↓
本地 Create 包裹物流
```

---

## 9. 第一笔测试不要接太复杂

推荐只用：

- 一张来源仓库；
- 一个接收港地址；
- 两边各一个远仓港；
- 一种普通原版物品；
- 数量 1～16；
- 接收端先直接接箱子或简单传送带。

第一笔成功后，再加远仓仪表、红石请求器、多港、多线路和自动补货。

---

## 如果没有成功

按包裹走过的顺序排查：

1. **两个终端是否加入同一张远仓网络？**
2. **两边的 Create 仓库是否已经通过远仓港正式加入这张网络？**
3. **终端是否只显示该网络的成员仓库，而不是空列表？**
4. **来源仓库有没有真的打出包裹？**
5. **包裹有没有进入发送港？**
6. **发送港是否显示无目的地、未激活或堵塞？**
7. **接收港是否加入正确的接收港地址？**
8. **接收港出口是否有空间？**
9. **远仓日志台有没有 WARN / ERROR？**

更详细的故障信息见：[监控与日志](监控与日志.md)。
